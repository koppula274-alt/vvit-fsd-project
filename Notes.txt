Web Applications :
----------------
   -> Any Application will be run on browsers is called as a web Applications

Types :
------
   1. Static web Applications:
  ---------------------------
      -> Any Web applications doesn't have functionalities
      -> To build Ststic web Applications we will only HTML &CSS
   
   2. Dynamic Web Applications:
   ---------------------------
      -> Any Web Applications having functionalities is called dynamic web Applications
      -> To Build dynamic web Applications HTML , CSS AND JS required

 HTML Boiler Plate:
 -----------------
    1. Tags:
    -------
        -> Tags are the predefine words which are enclosed with both opening and closing angular brackets
           Ex: 
              <h1> , <p> , <div>

    Types:
        1. Paired tags :
          --------------
            -> Any tags having both opening and closing tags is called as a Paired tags 
               Ex: 
                  1. All Heading tags 
                      
                      </body>
                          <h1>Heading 1</h1>
                          <h2>Heading 2</h2>
                          <h3>Heading 3</h3>
                          <h4>Heading 4</h4>     
                          <h5>Heading 5</h5>
                          <h6>Heading 6</h6>
                       </html> 
                  2. Formatting tags     
                       i. <b></b>               -> font bold
                       ii. <strong></strong>    -> font bold  
                       iii. <i></i>             -> italic
                       iv. <em><?em>            -> font italic
                       v. <marks></marks>       -> light the content
                       vi. <u></u>              -> underline
                       vii. <sub></sub>         -> subscript
                       viii. <sup></sup>        -> superscript
                       ix. <marquee></marqee>   -> to scroll the content
                       x. <center></center>     -> align content to center(only work for block level elements)
                       xi. <strick></strick>    ->                  
                  3. Other tags
